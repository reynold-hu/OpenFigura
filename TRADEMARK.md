# OpenFigura trademark policy

The code in this repository is licensed under AGPL-3.0. **The license does
not include any right to use the name "OpenFigura", its logo, or the
`figura_*` tool names in user-facing contexts.**

You may:

- Fork, modify, and run OpenFigura for any purpose the license allows.
- Describe accurately that your project "runs on OpenFigura", "is a fork of
  OpenFigura", or "is compatible with OpenFigura", without implying
  endorsement.

You may not:

- Ship a fork under the OpenFigura name, or a confusingly similar one.
  Rename it. This is free to do and is what the community expects.
- Offer a hosted service that presents itself as the official OpenFigura.
- Use the `figura_*` MCP tool names for a non-compatible implementation
  (clients route by tool name; a decoy breaks everyone's integrations).

Rationale: permissive licensing plus a protected name is how Blender, Linux,
and PostgreSQL kept one community while allowing unlimited forking. The
moat we want to build is the provenance schema and the backend conformance
suite — forks that re-implement them lose compatibility, which is a better
gravity well than any legal clause.

Questions or naming disputes: open an issue in the repository.
